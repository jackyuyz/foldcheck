## 不应加入的营销承诺

- 官方认证、保险/AppleCare 必然认可、设备真伪鉴定或报告时间经过可信认证。
- 整个 PDF 文件或所有可见页面都经过签名验证。
- 校准后的铰链绝对角度精度、终身折叠次数、后台持续统计、折痕物理深度。
- 电池健康、序列号、IMEI、Face ID 测试、自动修复、自动发现所有故障。
- 所有机型的全部摄像头和传感器必定可用，或用户确认项目都是自动测量。
- 无条件完全离线的购买/恢复、云同步、跨设备备份或未经确认的共享权益。
- 新图标已经采用、原生 Liquid Glass 图标已交付、尚未发生的审核通过或已上架状态。

## 本轮 Git 与发布边界

App 图标不变。此前“文案草稿不自动提交 Git”的限制属于原始撰写任务；后续用户已明确授权本轮开发、更新 spec、测试通过后推送 main。本轮可以随代码更新并推送事实校正后的审核草稿，仍不通过工具写入商店、不上传构建、不提交审核。
