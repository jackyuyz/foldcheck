## description

```text
一步步检查手机的响应，把你的观察留成记录。

FoldCheck 提供引导式屏幕与硬件检查，并为 iPhone Duo 提供内外屏、折痕及铰链测试。你可以开始完整检查，也可以直接进行触控、屏幕或铰链快速测试。没有铰链的受支持 iPhone，也能运行适用的检查项目。

屏幕与触控
滑动填满触控网格，或选择逐格点按。Duo 内屏折痕周围采用更密的网格，帮助检查该区域的触控响应。测试时可以旋转设备：已测的物理格子和进度会保留，继续触碰其他区域即可累计覆盖。还可检查多点触控，观察纯色画面，并手动标记可见的屏幕问题。

铰链与折痕
按照指引开合设备，并进行短暂的稳定性保持测试，查看铰链读数的连续性与一致性。折痕测试引导你从不同角度观察并评分，也可导入由其他设备拍摄的参考照片。铰链测试不承诺经过校准的绝对角度精度。

其他硬件检查
检查可用摄像头、扬声器测试音、麦克风录音与回放、运动传感器、距离感应、触感反馈及音量键。配备 Touch ID 的设备可进行相应检查。部分项目需要你确认看到、听到或感受到的结果；其他实体按键通过手动清单记录。不支持或当前不可用的项目会明确标注，也可以跳过测试。

免费检测，可选报告功能
适用的检测项目及屏幕上的结果免费提供，报告验证也可免费使用。

一次性 App 内购买可解锁 PDF 报告、已保存检查记录的查看、两次检查对比、可选的每月本地提醒，以及折叠统计。报告包含检测结果、备注和二维码。购买页面会显示当前价格，购买页面与设置中均可恢复购买。

记录保留在本机
无需注册 App 账号。除非你主动分享，检查数据保留在设备上。App 未接入广告或分析 SDK。检测和报告验证可离线进行；商品信息、购买及恢复购买使用 Apple 服务。

设置中可切换英语、简体中文、繁体中文、日语、法语和西班牙语。报告可跟随界面语言，也可固定使用英语。

了解检测边界
折叠统计仅计入 FoldCheck 在前台运行期间观察到的开合循环，不代表手机终身折叠次数。App 不读取电池健康、序列号或 IMEI，也不测量折痕的物理深度。

导入 PDF 时验证的是其中嵌入的已签名报告数据；扫描二维码时验证的是报告摘要的签名。这些验证不覆盖每一页 PDF 的可见内容，也不认证设备身份或设备时钟。报告是用户生成的检查记录，不是官方认证，也不保证设备不存在故障。

可用项目取决于设备硬件及系统支持。
```
