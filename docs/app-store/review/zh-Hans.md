```text
FoldCheck 是本地运行的引导式手机检查 App，无需注册或登录 App 账号，没有业务后端、广告或分析 SDK。检查数据、备注和导入附件保留在设备上，除非用户主动分享。商品信息、购买与恢复购买使用 Apple StoreKit 服务。

审核路径：
1. 首页选择完整检查，或触控、屏幕、铰链快速测试。适用检测及屏幕上的结果免费；测试可以跳过。“验证”功能也免费。
2. 铰链与折痕项目需要支持相关 API 的 iPhone Duo；实现按 iOS 27.1 及以上进行运行时限制。硬件评估请使用兼容真机。其他 iPhone 可运行适用项目；铰链相关项目标为不适用。模拟器或缺少硬件时，项目可能显示不可用。
3. Duo 外屏触控测试需合拢，内屏需展开；内屏折痕附近使用更密网格。旋转保持同一物理网格及覆盖进度。切换内外屏时暂停并要求确认，随后开始该屏幕的独立网格。
4. 触控测试简介及设置中的辅助功能提供逐格点按模式，只计入实际接触开始，不把拖动路径计为点按覆盖。视觉测试可选择因需要视觉协助而跳过，原因写入结果。界面也响应大字体与减少动态效果偏好。
5. 铰链测试包括两次引导开合与五秒保持，评估读数连续性及一致性，不宣称校准后的绝对角度精度。缺少读数时标为不可用；使用手动滑块会在结果中注明。
6. 摄像头、麦克风及二维码扫描按需请求权限。摄像头测试保留曝光与清晰度数值，不保存测试照片；麦克风录音为临时文件，测试结束时移除。折痕照片由用户通过系统选择器主动导入。拒绝权限可跳过相应项目。Touch ID 仅适用于提供它的设备；部分按键项目依赖用户确认。
7. 创建报告会打开一次性非消耗型内购 FoldCheck Reports，商品 ID 为 com.jackyu.foldcheck.reports。解锁内容为 PDF 导出、历史记录查看与对比、每月本地提醒及折叠统计。购买页与设置均有恢复购买。完整检查自动保存，快速检查可选择保存到历史记录；购买前也可保存，但历史查看受内购限制。
8. 解锁后，可在历史中选择两次检查进行对比。在设置中开启每月提醒并允许通知，提醒在本机安排。折叠统计仅累计 App 前台运行期间观察到的合拢至展开循环，不是设备终身折叠次数。
9. 设置可选择英语、简体中文、繁体中文、日语、法语及西班牙语；报告跟随界面语言或固定使用英语。
10. 验证页面可导入生成的 PDF 或扫描其二维码。PDF 导入验证嵌入的已签名报告数据；二维码验证报告摘要的签名。两者均不验证所有 PDF 页面的可见内容、设备身份、测量准确性或设备时钟。报告是用户生成的检查记录，不是官方认证。App 不读取电池健康、序列号或 IMEI，也不测量折痕的物理深度。

Release 不包含折叠模拟、示例历史或内购解锁参数等调试入口。Secure Enclave 不可用时，报告明确标记开发签名，不宣称使用了硬件支持的签名。
```
