# FoldCheck · iOS 26 icon refinements

Five edits of the existing app icon, generated with the built-in Image Gen tool. Option numbers match the order the new five images appeared in the chat; they do not refer to the previous exploration set.

Brief: preserve the original green background, horizontal phone display and checkmark. Make the checkmark itself feel folded, and explore layered glass, controlled highlights, translucent edges and shallow depth.

Reference: the repository's original `AppIcon-1024.png` was inspected and attached as the edit target to every generation.

| Option | File | Direction |
|---|---|---|
| 1 | [01-creased-ribbon.png](01-creased-ribbon.png) | Creased Ribbon |
| 2 | [02-twin-leaves.png](02-twin-leaves.png) | Twin Glass Leaves |
| 3 | [03-folded-back.png](03-folded-back.png) | Folded Back |
| 4 | [04-frosted-valley.png](04-frosted-valley.png) | Frosted Valley |
| 5 | [05-shared-fold.png](05-shared-fold.png) | Shared Fold |

These PNGs are concept previews. The original generated images are preserved without resizing or retouching. They are not a native layered Icon Composer export. Actual runtime Liquid Glass appearances require separately prepared icon layers after a visual direction is selected.

Design reference: [Apple app icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons/), [Icon Composer](https://developer.apple.com/icon-composer/).

Full generation prompts and original generation filenames are in [prompts.json](prompts.json).
