# App icon

`AppIcon.svg` is the source. It shows the inner display fully open with the center crease, and the check mark's vertex sits on the crease. Colors match the app: brand green `#0e7a45`, body `#1c1e21`, crease `#8b93a1`.

`AppIcon-1024.png` is exported from the SVG with headless Chrome (1024×1024, no alpha) and copied to `App/Resources/Assets.xcassets/AppIcon.appiconset/`. iOS applies the rounded mask, so the PNG stays square.
